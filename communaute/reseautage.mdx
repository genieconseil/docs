## Votre profil professionnel GénieConseil

Votre profil GénieConseil est votre vitrine professionnelle dans la communauté mondiale de l'ingénierie :

| Élément du profil | Description |
|-------------------|-------------|
| **Spécialités** | Vos disciplines et domaines d'expertise |
| **Expérience** | Années d'expérience, secteurs, types de projets |
| **Certifications** | Titre professionnel (ing., P.Eng., PE, etc.) |
| **Contributions** | Réponses au forum, guides rédigés, évaluations |
| **Réputation** | Score calculé par la communauté basé sur vos contributions |
| **Portfolio** | Projets réalisés (avec permission) |
