## Introduction

La littérature scientifique est le fondement de la pratique d'ingénierie fondée sur les données probantes. Ce répertoire recense les principales revues par discipline, les publications canadiennes d'intérêt, les ressources en accès libre et les outils pour gérer votre veille documentaire. Les facteurs d'impact (IF) mentionnés sont approximatifs et varient d'une année à l'autre selon les données de Clarivate (Web of Science).

<Info>
Les facteurs d'impact (IF) sont calculés sur une fenêtre de deux ans (nombre de citations reçues divisé par le nombre d'articles publiés). Ils varient significativement entre disciplines — un IF de 3 est excellent en génie civil mais modeste en biologie moléculaire. Comparer les IF entre disciplines différentes n'est pas significatif.
</Info>

## Ressources en accès libre (Open Access)

<CardGroup cols={2}>
  <Card title="arXiv" icon="file-code" href="https://arxiv.org">
    Prépublications (preprints) en physique, mathématiques, informatique et ingénierie. Sections pertinentes : cs.SY (systèmes de commande), cond-mat (matériaux), physics.flu-dyn (fluides). Gratuit et immédiat.
  </Card>
  <Card title="ResearchGate" icon="users" href="https://www.researchgate.net">
    Réseau social académique — les auteurs y partagent souvent leurs articles même lorsque la revue est payante. Fonctionnalité de demande directe à l'auteur.
  </Card>
  <Card title="Semantic Scholar" icon="magnifying-glass" href="https://www.semanticscholar.org">
    Moteur de recherche académique de l'Allen Institute for AI. Extraction des résultats clés, graphe de citations, résumés générés par IA.
  </Card>
  <Card title="Google Scholar" icon="google" href="https://scholar.google.com">
    Index bibliographique universel — trouve souvent des versions en accès libre des articles. Alertes de citation disponibles.
  </Card>
</CardGroup>

<CardGroup cols={2}>
  <Card title="PubMed" icon="stethoscope" href="https://pubmed.ncbi.nlm.nih.gov">
    Base de données biomédicale de la US National Library of Medicine — indispensable pour le génie biomédical et environnemental.
  </Card>
  <Card title="Europe PMC" icon="microscope" href="https://europepmc.org">
    Équivalent européen de PubMed, inclut les mandats de dépôt des organismes de financement (dont IRSC/CIHR au Canada).
  </Card>
  <Card title="Unpaywall (extension)" icon="lock-open" href="https://unpaywall.org">
    Extension Chrome/Firefox qui trouve automatiquement les versions en accès libre des articles derrière paywall. Indispensable pour tous les chercheurs.
  </Card>
  <Card title="Open Alex" icon="database" href="https://openalex.org">
    Index ouvert de 250 millions d'œuvres académiques — alternative open source à Scopus et Web of Science, avec API gratuite.
  </Card>
</CardGroup>

## Outils de gestion des références bibliographiques

<CardGroup cols={2}>
  <Card title="Zotero" icon="bookmark" href="https://www.zotero.org">
    Gestionnaire de références gratuit et open source. Capture automatique depuis les navigateurs, synchronisation cloud (300 Mo gratuit), partage de bibliothèques en groupe. Fortement recommandé.
  </Card>
  <Card title="Mendeley" icon="layer-group" href="https://www.mendeley.com">
    Gestionnaire de références Elsevier. Intégration avec Scopus. Version gratuite disponible. Réseau social académique intégré.
  </Card>
  <Card title="EndNote" icon="pen" href="https://endnote.com">
    Gestionnaire de références complet — souvent disponible via licence institutionnelle dans les universités. Excellent pour les grandes bibliothèques et la collaboration.
  </Card>
  <Card title="JabRef" icon="code" href="https://www.jabref.org">
    Gestionnaire open source orienté LaTeX/BibTeX — idéal pour les ingénieurs utilisant LaTeX pour leurs thèses et articles.
  </Card>
</CardGroup>

<Tip>
L'extension **Unpaywall** pour Chrome ou Firefox est peut-être l'outil le plus utile pour accéder légalement aux articles scientifiques. Elle vérifie automatiquement les dépôts institutionnels, PubMed Central et les archives d'auteurs pour trouver des versions en accès libre légitimes. Plus de 50 % des articles récents ont une version accessible librement.
</Tip>
